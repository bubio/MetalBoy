# Contracts: CLI 契約

**Branch**: `001-gb-cli-emulator` | **Date**: 2026-10-18

CLI の用法・オプション・終了コード・メッセージ出力の正式な契約。
実装（MBOptionParser / MBEmulatorSession）と quickstart の検証手順は
本契約に準拠する。

## 用法

```text
MetalBoy [--scale N] [--volume P] <rom-path>

  <rom-path>    Game Boy ROM ファイルのパス（必須、位置引数 1 個のみ）
  --scale N     画面スケール。整数 1〜8（既定 3）。FR-003
  --volume P    音量。整数 0〜100（パーセント記号なし、既定 50）。FR-004
```

## 動作契約

1. 引数は任意の順序で受け付け、組み合わせは自由（例: `--scale 1` のみ、
   `--volume 0` のみ）。
2. 同一オプションの重複指定は最後の値を有効とする（衝突エラーにしない。
   テスト容易性のための既定動作）。
3. 範囲外の値は失敗（FR-005）。例:
   - `--scale 0` / `--scale 9` / `--scale abc`
   - `--volume 150` / `--volume -1`
4. ROM 未指定 / 2 個以上の位置引数 / 未知のオプション → 使い方表示で失敗。
5. 一切の設定ファイル・環境変数を読まない（FR-006）。永続化もしない。

## 終了コード

| コード | 意味 | 出力先 |
|---|---|---|
| 0 | 正常終了（ゲーム終了 / ウィンドウを閉じる / Ctrl+C） | なし |
| 1 | ランタイムエラー（ROM 不在・無効・非対応マッパー・CGB 専用・ セーブ読書き失敗） | stderr に原因 1 行 |
| 2 | 引数解析エラー（未指定・範囲外・未知オプション） | stderr に許容範囲つき 1 行 + 使い方 |

## メッセージの言語と形式

- すべて日本語。1 行で原因を述べ、必要なら許容範囲を併記する
  （例: `画面スケールは 1〜8 で指定してください（指定値: 9）`）。
- 正常起動時に stdout への通知（進行情報等）は出力しない
  （ゲーム画面・音声が唯一の出力）。
